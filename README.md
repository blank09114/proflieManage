# 사이트 이용 안내

- 메인 화면에서 캐릭터의 프로필과 소개를 확인할 수 있습니다.
- **피드 보기**를 누르면 사진이 펼쳐지고, 사진을 누르면 크게 볼 수 있습니다. 확대 창 바깥을 누르면 닫힙니다.
- 오른쪽 아래 **연필 버튼**을 누르고 전달받은 비밀번호를 입력하면 수정 화면으로 이동합니다.
- 수정 화면에서 프로필, 소개, 키워드, 사진과 테마 색상을 변경할 수 있습니다. 키워드는 쉼표로 구분해 입력합니다.
- 섹션의 **순서 이동** 버튼이나 피드의 파일 제목을 드래그하면 순서를 바꿀 수 있습니다.
- 소개 내용에는 `*굵게*`, `_밑줄_`, `/기울임/`, `-취소선-`을 사용할 수 있습니다. `| 항목 | 내용 |`처럼 입력하면 표로 표시됩니다.
- 사진은 JPG·JPEG·PNG 파일을 사용할 수 있으며, 한 장당 최대 10MB, 피드는 최대 50장까지 등록할 수 있습니다.
- 수정을 마친 뒤 **저장**을 눌러 주세요. 저장 성공 안내를 확인한 후 화면을 닫거나 로그아웃하면 됩니다.
